# 🐍 Python Assignments

A collection of Python programming assignments created while learning Python fundamentals. This repository contains solutions to various programming problems covering core Python concepts, helping beginners strengthen their coding skills through practical exercises.

---

## 📖 About

This repository is designed to practice Python programming from beginner to intermediate level. Each assignment focuses on a specific concept and helps improve logical thinking and problem-solving skills.

Whether you're new to Python or revising the basics, these assignments provide hands-on experience with real coding exercises.

---

## 🎯 Objectives

- Learn Python syntax
- Build problem-solving skills
- Practice writing clean Python code
- Strengthen programming fundamentals
- Prepare for Data Structures, Machine Learning, and AI
